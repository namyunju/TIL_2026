## LangGraph
상태관리 기반 AI Agent 구축 위한 라이브러리 

기존 선형적인 구조 LangChain에서 **순환 구조**가 포함된 그래프 기반 워크플로우를 설계

**반복(Loops)** / **조건부 제어** / **상태유지**

각 Node에서 작업 실행. Edge에서 다음 작업을 지정. 그래프 전체에서 State를 공유하여 각 Node에서 상태를 읽고 수정할 수 있음.


상태관리, 순환지원, 세밀한 제어, HILP 특장점을 가짐
